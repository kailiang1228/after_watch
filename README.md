# After_Watch (待看清單)

這是一個簡單的靜態網頁應用程式，用於管理您的電影、劇集和動畫待看清單。

## 功能特色

- **分類管理**：支援電影、劇集、動畫三種分類。
- **新增項目**：可以隨時新增想看的影片。
- **狀態標記**：點擊項目即可標記為高亮（例如：已看過或重點標記）。
- **刪除功能**：每個項目後方都有刪除按鈕。
- **資料持久化**：使用瀏覽器的 `LocalStorage` 儲存資料，重新整理頁面後資料不會消失。
- **匯入/匯出**：支援將清單匯出為 JSON 檔案，或從 JSON 檔案匯入，方便備份或轉移資料。
- **一鍵重置**：可隨時重置回預設清單。

## 使用方法

1.  直接用瀏覽器開啟 `index.html` 即可使用。
2.  **新增**：在上方輸入框輸入標題，選擇類別，點擊「新增項目」。
3.  **標記**：點擊清單中的項目文字即可切換高亮狀態。
4.  **刪除**：點擊項目右側的 `x` 按鈕即可刪除。
5.  **備份**：點擊「輸出片單」下載 JSON 檔；點擊「讀取片單」上傳備份。
